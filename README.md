# Superstore Sales Analytics Dashboard

A 4-page interactive Power BI dashboard for analyzing sales, profit and customer purchasing patterns on the Superstore dataset. Built during my work at Titus Solution.

## Overview
The dashboard helps users track business performance through KPI cards, interactive filters and a range of charts. A custom data model and DAX measures drive all the calculations.

## Key Features
- **KPI cards** for total sales, total profit, total quantity, average order value (AOV) and profit margin
- **7 DAX measures**: total sales, total profit, total quantity, AOV, margin, revenue per unit and profit per unit
- **Slicers** for year, region, segment, category, sub-category and ship mode
- **Multiple chart types**: clustered column, line, donut, waterfall and scatter charts
- **Detail table** for drilling into individual records
- Dark theme with a consistent colour palette across all pages

## Dashboard Pages
| Page | Focus |
|------|-------|
| Page 1 | Overall sales and profit summary |
| Page 2 | Performance breakdown with waterfall analysis |
| Page 3 | Trends over time and category share |
| Page 4 | Profit vs sales relationship and detailed records |

## Tech Stack
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data modeling

## How to Open
1. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows only)
2. Download `titus_soln.pbix` from this repository
3. Open the file in Power BI Desktop
4. Use the slicers to filter the data and explore the pages

## Dataset
The Superstore sales dataset, with fields such as Order Date, Region, Segment, Category, Sub-Category, Ship Mode, Sales, Quantity and Profit.
